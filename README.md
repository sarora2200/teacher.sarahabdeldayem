# Learning with Noor | نور للتعلّم

A responsive bilingual (English/Arabic) starter website for a Quran, Arabic, and Islamic Studies teacher.

## Included features
- Responsive homepage and learning paths for Quran & Tajweed, Arabic, and Islamic Studies
- English/Arabic interface toggle (starter translations for core navigation and key headings)
- YouTube video library placeholders
- Books and worksheet resource list
- Arabic-letter multiple-choice quiz
- Arabic phrase audio practice using the browser's speech synthesis (availability varies by device)
- Homework and revision checklist saved locally in the student's current browser
- Lesson inquiry / booking call-to-action
- Responsive mobile navigation

## Files
- `index.html` — page content
- `style.css` — design, layout, and responsive styles
- `script.js` — navigation, language toggle, quiz, audio, and checklist

## Personalize before publishing
1. Replace `Learning with Noor` with your preferred name if needed.
2. Update the welcome text and teaching details.
3. Replace placeholder YouTube URLs with your own videos.
4. Replace resource placeholders with your PDFs or trusted resources you have permission to share.
5. Replace `YOUR-EMAIL@example.com` in the lesson button with your teaching email, or replace the button URL with your Preply/booking profile link.
6. For reliable audio, consider adding your own recordings. Browser text-to-speech varies by device and is not appropriate for Quran recitation or precise Tajweed instruction.
7. Open `index.html` in a browser to preview the site.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new repository, for example `quran-learning-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root (top level).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Your address will look like `https://YOUR-USERNAME.github.io/quran-learning-website/`.
7. If you update files later, commit the changes and GitHub Pages will publish the new version.

Official guide: https://docs.github.com/en/pages/quickstart

## Important limitations
GitHub Pages hosts static websites. This starter does not provide student accounts, a private teacher dashboard, online homework submission, or shared progress tracking. Checklist progress is stored only in the current browser on the current device. For real booking, use a mailto link or a trusted booking platform. Avoid collecting children's personal information unless you have a suitable privacy process.
