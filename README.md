# Learning with Noor — educational website starter

A responsive starter website for a Quran, Arabic, and Islamic Studies teacher. It includes:
- Home page and subject cards
- YouTube lesson placeholders
- Books and worksheet resource list
- A simple Arabic-letter quiz
- A homework checklist saved locally in the student's browser
- Responsive mobile navigation

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — quiz, navigation, and homework checklist behaviour

## Personalize before publishing
1. Replace **Learning with Noor** with your preferred teacher/website name.
2. Update the introduction and learning paths to match your teaching.
3. Replace placeholder YouTube links (`https://www.youtube.com/`) with your own lesson links.
4. Replace the `href="#"` resource placeholders with links to your PDFs or trusted resources you have permission to share.
5. Add your contact or booking link if you want one.
6. Preview `index.html` in your browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new repository, for example `quran-learning-website`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository's root (top level).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The public address will look like `https://YOUR-USERNAME.github.io/quran-learning-website/`.

## Important limitations
GitHub Pages hosts static websites. This starter has no student accounts, private teacher dashboard, online submissions, or shared progress database. The homework checklist is saved only in the current browser on the current device. For collecting homework or tracking students across devices, connect a form or backend service later. Avoid collecting children's personal information unless you have a suitable privacy process.
